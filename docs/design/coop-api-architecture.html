coop-api — the irl.coop sovereign stack hub
One Fastify process (apps/coop-api, host :3001) = auth bridge + OIDC fleet gateway + group model + relayer + docs/files + bus + appservice + mail. 69 routes, browsable at https://api.irl.coop/api/docs.

What coop-api is

  • • One Fastify process on the host (:3001)
  • • The identity hub: mints the coop JWT, answers OIDC discovery
  • • 16 route modules + the SMTP relay
  • • 69 documented routes (Swagger /api/docs)

Inbound / identity

  • • Keycloak + Google broker (the real IdP)
  • • Stalwart webhook (mail.received → bus)
  • • Internal: Keycloak groups mapper, app event ingest
  • • OIDC clients (plane, nocodb, matrix, formbricks-gate…)

Outbound / integrations

  • • Stalwart via XOAUTH2 (mailer + SMTP relay :1025)
  • • Redis (pub/sub), Citus Postgres, MinIO S3
  • • Matrix appservice, FusionPBX, Open-Meteo
  • • Temporal worker (separate process, digests)
