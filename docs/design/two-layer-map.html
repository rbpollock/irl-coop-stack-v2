Click a domain. Or run the rebuild simulation — the interesting column is the third one, which is the only tier with no commitment behind it and no derivation path back.

Truth flows one way: chain → projection, never the reverse except through an authorised transaction. Where the two disagree, the chain wins — and a disagreement should be surfaced, not reconciled silently.
