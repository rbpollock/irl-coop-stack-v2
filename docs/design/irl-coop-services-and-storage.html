irl.coop Services & Storage

Conceptual map — how the web interface, core services, and storage mechanisms interact

Identity & access

  • • Keycloak is the OIDC hub for every service
  • • Zero per-service credentials (XOAUTH2 · STS · JWT rooms)
  • • Web interface authenticates once, services via OIDC

Integration hub

  • • The UI talks directly to coop-api only (REST · JWT)
  • • coop-api: onboarding · provisioning · Safe deploy · query proxy
  • • Every other service is reached via OIDC sign-in

Storage split

  • • Relational: Citus (realm · state · metadata)
  • • Objects: MinIO (files · media · attachments)
  • • Secrets: Vault (threshold) · Truth: shared chain
