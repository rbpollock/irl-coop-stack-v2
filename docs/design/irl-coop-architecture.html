irl.coop Architecture

Sovereign federated stack — Safe accounts, core services, declarative deployment

Sovereignty & custody

  • • Threshold keys only — no TEE, no Lit (pure crypto)
  • • Group vault: secrets only a quorum can open
  • • Uncorrelatable Safe addresses (CREATE2, zero storage)
  • • Recovery never depends on the backend

Declarative deployment

  • • site.yaml → renderer → Ansible (idempotent converge)
  • • One manifest per site; git is the deployment record
  • • Traefik routes generated from the manifest
  • • Secrets via ansible-vault, never inline

Federation

  • • Shared chain = global truth (Safes, registry, consent)
  • • Per-site autonomy: local identity, mail, data
  • • Links: OIDC trust · SMTP · Matrix federation
  • • Colocation = a group deploys its own site manifest
